# Android Signing Quick Start

This is a quick reference for setting up Android APK signing. See [ANDROID_SIGNING_SETUP.md](./ANDROID_SIGNING_SETUP.md) for the complete guide.

## One-Command Setup

```bash
keytool -genkey -v -keystore "src-tauri/gen/android/app/upload-keystore.jks" -keyalg RSA -keysize 2048 -validity 10000 -alias upload -storepass android -keypass android -dname "CN=Tauri App, OU=Development, O=MyCompany, L=City, S=State, C=US"
```

## Create key.properties

File: `src-tauri/gen/android/key.properties`

```properties
storePassword=android
keyPassword=android
keyAlias=upload
storeFile=upload-keystore.jks
```

## Configure build.gradle.kts

File: `src-tauri/gen/android/app/build.gradle.kts`

Add the following configuration to enable signing:

1. **Add imports** at the top:

```kotlin
import java.util.Properties
import java.io.FileInputStream
```

2. **Load key properties** after the tauriProperties section:

```kotlin
val keyPropertiesFile = rootProject.file("key.properties")
val keyProperties = Properties()
if (keyPropertiesFile.exists()) {
    keyProperties.load(FileInputStream(keyPropertiesFile))
}
```

3. **Add signingConfigs** in the android block (after defaultConfig):

```kotlin
signingConfigs {
    create("release") {
        if (keyPropertiesFile.exists()) {
            keyAlias = keyProperties["keyAlias"] as String
            keyPassword = keyProperties["keyPassword"] as String
            storeFile = file(keyProperties["storeFile"] as String)
            storePassword = keyProperties["storePassword"] as String
        }
    }
}
```

4. **Apply signing to release build** in the release buildType:

```kotlin
getByName("release") {
    isMinifyEnabled = true
    if (keyPropertiesFile.exists()) {
        signingConfig = signingConfigs.getByName("release")
    }
    // ... rest of release config
}
```

## Build and Install

```bash
# Build
npm run tauri android build -- --release

# Install
adb install src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release.apk
```

## Verify Setup

```bash
# Check keystore
keytool -list -v -keystore src-tauri/gen/android/app/upload-keystore.jks -storepass android

# Check files exist
ls src-tauri/gen/android/key.properties
ls src-tauri/gen/android/app/upload-keystore.jks
```
